# Proyecto V3RIDIA

Sistema integral compuesto por una aplicación móvil y un servidor local.

## Estructura del Proyecto
* **Frontend:** Desarrollado en Flutter (Dart). Todo el código fuente se encuentra dentro de la carpeta `v3ridia`.
* **Backend:** Servidor API desarrollado en Python utilizando el framework Flask y Django. Los archivos de arranque (`app.py`) y el entorno virtual (`venv`) se encuentran en la raíz.
* **Bases de Datos:** Integración configurada con Firebase y Supabase.
